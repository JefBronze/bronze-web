# bronze-web

Site da Bronze Engenharia de Energia — **bronze-engenharia.com.br**.

Um observatório de energia: instrumentos ao vivo alimentados por dados públicos (ONS, Hydro-Québec, NYISO, CAISO, FRED, Polymarket, Kalshi, ANEEL), desenhados à mão em SVG. Português brasileiro em `/`, inglês em `/en`.

Estado: **fase 0 — brief de design**. Ainda não há código do site.

- `docs/plano.md` — plano aprovado (conceito, seções, fontes de dados, arquitetura, fases).
- `design-brief.md` — brief para o Claude Design.
- `design-data.json` — snapshot real de todas as fontes (gerado por `python3 scripts/snapshot.py`, só biblioteca-padrão).
- `docs/conteudo-v1.md` — rascunho institucional anterior, mantido como referência.
